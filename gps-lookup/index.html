    GPS-Standortdaten

    Beim Erfassen eines Eintrags fragt die App über die Geolocation-Funktion Ihres Browsers Ihren aktuellen Standort ab (Art. 6 Abs. 1 lit. a DSGVO, Einwilligung über die Browser-Berechtigungsabfrage). Die Koordinaten werden ausschließlich lokal im localStorage Ihres Geräts gespeichert.

    Adress-Auflösung (Reverse-Geocoding)

    Um aus GPS-Koordinaten eine Adresse anzuzeigen, sendet die App die erfassten Koordinaten an den Dienst Nominatim / OpenStreetMap (OpenStreetMap Foundation). Dabei kann die IP-Adresse an diesen Dienst übermittelt werden. Es findet keine Übertragung an GZ-AI.-Stacks selbst statt.

    Kartenansicht

    Wird die optionale Kartenansicht geöffnet, lädt die App Kartenkacheln von OpenStreetMap sowie die Bibliothek Leaflet über das CDN unpkg.com nach. Dabei können die üblichen technischen Verbindungsdaten (IP-Adresse) an diese Dienste übermittelt werden.

    Lokal gespeicherte Daten

    Alle erfassten Einträge (Standort, Adresse, Uhrzeit, Anzahl) verbleiben in localStorage auf Ihrem Gerät und werden nicht an einen eigenen Server übertragen. Export-Funktionen (CSV, GPX, JSON-Backup) speichern Dateien nur auf Ihrem eigenen Gerät.

    Speicherdauer

    Die Daten verbleiben lokal, bis Sie sie selbst löschen (einzelne Einträge in der App oder Websitedaten im Browser löschen).

    Ihre Rechte

    Sie haben das Recht auf Auskunft, Berichtigung, Löschung, Einschränkung der Verarbeitung sowie Datenübertragbarkeit. Da alle Daten lokal auf Ihrem Gerät liegen, können Sie diese Rechte direkt über die Lösch-/Export-Funktionen der App wahrnehmen.
