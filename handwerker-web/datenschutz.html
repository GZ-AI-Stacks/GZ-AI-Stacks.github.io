KURZFASSUNG

GZ Handwerker-Web ist eine Offline-Anwendung. Sie kommt ohne Konto, ohne Login und ohne eigenen Server aus. Alles, was Sie eingeben (Firmendaten, Leistungen, Galeriebilder, Farben), bleibt ausschließlich lokal in Ihrem Browser bzw. wird in die von Ihnen exportierte HTML-Datei geschrieben. 2. Lokale Speicherung im Browser (localStorage)

GZ Handwerker-Web speichert Ihre Eingaben im sogenannten localStorage Ihres Browsers. Das ist ein Speicherbereich auf Ihrem eigenen Gerät. Gespeichert werden:

  • Ihre Konfiguration (Firmendaten, Leistungen, Farben, Bilder als Data-URI),
  • Ihr aktivierter Lizenzschlüssel.

Diese Daten verlassen Ihr Gerät nicht. Sie werden nicht an uns oder an Dritte übertragen. Sie können sie jederzeit selbst löschen, indem Sie die Daten der Website in Ihren Browser-Einstellungen entfernen.

3. Keine Cookies, kein Tracking

GZ Handwerker-Web setzt keine Tracking-Cookies, nutzt keine Analyse-Werkzeuge (z. B. Google Analytics) und erstellt keine Nutzerprofile.

4. Keine externen Inhalte (CDN-frei)

LOKAL EINGEBETTET

Alle Schriften und Symbole sind direkt in der Anwendung enthalten. GZ Handwerker-Web lädt keinerlei Inhalte von externen Servern (Content Delivery Networks) nach – es wird keine IP-Adresse an Dritte übertragen. Die Anwendung funktioniert vollständig offline.

5. Hinweis zu den exportierten Websites

Die mit GZ Handwerker-Web erzeugten Websites sind statische HTML-Dateien. Sie enthalten ausschließlich die von Ihnen eingegebenen Inhalte. Für die Datenverarbeitung auf der Website Ihres Handwerksbetriebes (etwa bei Einsatz beim Hoster, in Kontaktformularen oder bei der Einbindung externer Dienste) sind Sie als Betreiber selbst verantwortlich.
