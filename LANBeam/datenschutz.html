Daten-Prinzip

LANBeam folgt dem Prinzip der Datenminimierung nach DSGVO Art. 5 Abs. 1 lit. c:

  • Es werden nur die Daten erhoben, die für die unmittelbare Funktion nötig sind (Datei-Transfer im LAN).
  • Es werden keine Daten an Dritte übermittelt.
  • Es werden keine Daten über das technisch notwendige Maß hinaus gespeichert.
  • Es gibt kein Backend, keine Cloud, keinen Login.

Installation

Bei der Installation der Software werden keine Daten an uns übermittelt. Die Software wird lokal aus dem ZIP-Archiv entpackt und auf Ihrem Computer installiert.

Falls Sie die Software über den Microsoft Store beziehen, gilt zusätzlich die Datenschutzerklärung von Microsoft. Wir haben darauf keinen Einfluss.

Nutzung

Was passiert beim Datei-Transfer?

Wenn Sie eine Datei senden, geschieht folgendes:

  • Ihr Computer baut eine direkte TCP-Verbindung zum Empfänger-Gerät im lokalen Netzwerk auf.
  • Die Datei wird über diese Verbindung an den Empfänger geschickt.
  • Die Datei wird beim Empfänger im konfigurierten Speicherort gespeichert.
  • Wir sehen nichts davon. Es läuft kein Server, kein Relay, kein Vermittler.

Welche Daten sind technisch im Netzwerk sichtbar?

Im lokalen Netzwerk werden zur Geräte-Erkennung folgende Informationen über UDP-Multicast verteilt:

DatumZweckEmpfänger
Geräte-Name (frei wählbar)Anzeige in Empfänger-ListeGeräte im selben LAN
Zufällige Geräte-ID (UUID)Eindeutige IdentifikationGeräte im selben LAN
IP-Adresse + PortVerbindungs-AufbauGeräte im selben LAN
Protokoll-VersionKompatibilitäts-PrüfungGeräte im selben LAN

Sie können jeden Geräte-Namen frei wählen. Wenn Sie nicht Ihren echten Namen verwenden wollen, nennen Sie das Gerät z. B. "Mein PC".

Werden Inhalte der Dateien analysiert oder gespeichert?

Nein. Die Software liest Dateien nur, um sie zu übertragen. Es findet keine Inhalts-Analyse statt, keine Indexierung, kein Scannen, keine Vorschau-Erzeugung auf Server-Seite.

Empfänger-Seite (Web-Portal für Handys)

LANBeam kann optional einen kleinen lokalen Web-Server starten, über den Sie Dateien von einem Handy oder anderen Gerät im Browser hochladen können.

  • Der Web-Server läuft nur auf Ihrem PC im lokalen Netzwerk.
  • Er ist von außerhalb Ihres Heim-Netzwerks nicht erreichbar (kein Port-Forwarding aktiviert).
  • Die hochgeladenen Dateien werden im konfigurierten Speicherort abgelegt.
  • Es werden keine Zugriffs-Logs an externe Stellen gesendet.

Lokale Konfigurations-Datei

LANBeam speichert Einstellungen in einer JSON-Datei auf Ihrem Computer:

%APPDATA%\LANBeam\config.json

Inhalt:

  • Gewählte Sprache (de / en)
  • Geräte-Name
  • Speicherort für empfangene Dateien
  • Status "First-Run erledigt" (ja / nein)

Diese Datei verlässt Ihren Computer nicht.

Firewall-Regeln

Im Setup-Wizard kann LANBeam Sie fragen, ob Windows-Firewall-Regeln eingerichtet werden sollen. Diese Regeln erlauben eingehende Verbindungen aus dem lokalen Netzwerk auf die für den Transfer benötigten Ports (53317 UDP, 53318 TCP, 53319 TCP).

Sie können diese Regeln jederzeit in der Windows-Firewall-Konfiguration entfernen (Systemsteuerung → Windows Defender Firewall → Erweiterte Einstellungen).
