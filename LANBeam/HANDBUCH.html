Was ist LANBeam?

LANBeam ist ein Werkzeug für Windows zum schnellen Versenden von Dateien zwischen Geräten im selben WLAN oder LAN. Ohne Cloud, ohne Konto, ohne Server irgendwo im Internet.

KERN-PRINZIP

Alles bleibt lokal. Wenn dein WLAN ausfällt, funktioniert LANBeam trotzdem — weil keine Internet-Verbindung gebraucht wird.

Installation

  1. ZIP-Datei Nova-Drop-Setup.zip entpacken (Rechtsklick → Alle extrahieren).
  2. Im entpackten Ordner INSTALL.bat doppelklicken.
  3. Windows fragt eventuell nach Bestätigung (SmartScreen). Auf "Weitere Informationen" klicken, dann "Trotzdem ausführen".
  4. LANBeam wird installiert nach %LocalAppData%\Programs\LANBeam\.
  5. Es entstehen Verknüpfungen auf dem Desktop und im Startmenü.

KEIN .NET NÖTIG

Die nötige .NET-8-Laufzeit ist im Programm enthalten. Du musst nichts extra installieren.

Erster Start

Beim ersten Start öffnet sich ein kurzer Setup-Wizard mit fünf Schritten:

  1. Sprache — Deutsch oder Englisch.
  2. Geräte-Name — so siehst du dein Gerät auf anderen Computern (z. B. "Wohnzimmer-PC").
  3. Speicherort — wohin werden empfangene Dateien gespeichert.
  4. Firewall — einmaliger Klick auf "JETZT EINRICHTEN", dann Windows-Bestätigung mit "Ja". Damit kann LANBeam über dein Netzwerk reden. Wichtig.
  5. Fertig. Hauptfenster öffnet sich.

Dateien senden

Auf beiden Geräten muss LANBeam laufen und beide müssen im selben WLAN/LAN sein.

  1. Links unter "GERÄTE IN DER NÄHE" erscheinen automatisch alle anderen PCs mit LANBeam.
  2. Klick auf den gewünschten Empfänger.
  3. Drei Wege Dateien zu schicken:
    • Datei(en) ins Fenster ziehen (Drag & Drop)
    • Klick auf DATEIEN WÄHLEN…
    • Klick auf ORDNER WÄHLEN… (alle Dateien rekursiv)
  4. Fortschrittsbalken unten zeigt Tempo und Anzahl.
  5. Auf der Empfänger-Seite landet alles im eingestellten Speicherort.

Handy ohne Installation

Du musst auf dem Handy nichts installieren. Es reicht der Browser:

  1. Im Hauptfenster siehst du eine Box "AUF HANDY / ANDEREM GERÄT ÖFFNEN" mit URL und QR-Code.
  2. Mit der Handy-Kamera den QR-Code scannen, oder die URL im Browser eintippen.
  3. Auf der Drop-Seite auf CHOOSE FILES tippen, Fotos / Dateien auswählen, SEND.
  4. Dateien kommen direkt am PC an.

HANDY UND PC IM SELBEN WLAN

Falls dein Handy im Mobilfunk-Netz ist, gehe ins Heim-WLAN. Sonst sind PC und Handy nicht im selben Netzwerk und finden sich nicht.

Einstellungen

LANBeam merkt sich deine Einstellungen automatisch. Sie liegen unter %APPDATA%\LANBeam\config.json.

  • Speicherort für Downloads — im Hauptfenster Knopf SPEICHERORT ÄNDERN…
  • Sprache — Knöpfe DE / EN in der Titelleiste

Netzwerk und Firewall

LANBeam verwendet drei Netzwerk-Ports im lokalen Netz:

PortProtokollZweck
53317UDPGeräte-Erkennung im LAN (Multicast)
53318TCPDatei-Empfang von anderen PCs mit LANBeam
53319TCPWeb-Portal für Handy-Browser

Die Firewall-Regeln werden im Setup-Wizard einmalig automatisch eingetragen. Falls du sie später manuell ändern willst: Windows-Einstellungen → Datenschutz und Sicherheit → Windows-Sicherheit → Firewall & Netzwerkschutz.

Fehlerbehebung

Anderes Gerät erscheint nicht in der Liste

  • Beide PCs im selben WLAN? ipconfig in PowerShell zeigt deine IP. Beide müssen im gleichen Subnetz sein (z. B. 192.168.178.x).
  • Netzwerkprofil auf "Privat" stellen, nicht "Öffentlich". Sonst blockt Windows die Erkennung.
  • Firewall beim Setup übersprungen? → Setup nochmal manuell starten.
  • Mehrere Router in Reihe (z. B. WLAN-Repeater oder zweiter Router)? Geräte können in unterschiedlichen Subnetzen landen. Lösung: Asus / Repeater auf Access-Point-Modus stellen.
  • Gast-WLAN? Da ist meistens AP-Isolation aktiv. Wechsle ins Haupt-WLAN.

Handy kann URL nicht öffnen

  • Handy im selben WLAN wie der PC? Mobilfunk reicht nicht.
  • Firewall am PC eingerichtet?
  • VPN am Handy oder PC aktiv? Ausschalten.

Transfer ist langsam

  • Schwaches WLAN-Signal: Notebook näher zum Router oder mehr Antennen-Nähe.
  • Auf 2,4 GHz statt 5 GHz: Im Router-Menü 5 GHz aktivieren oder in WLAN-Eigenschaften "5 GHz Band bevorzugen" einstellen.
  • Anti-Virus scannt jede Datei: Echtzeit-Scan kurz pausieren als Test.

Datenschutz

LANBeam sendet keine Daten an externe Server. Es gibt keinen Cloud-Account, keine Telemetrie, keine Werbung.

  • Dateien gehen direkt von Gerät A zu Gerät B im lokalen Netz.
  • Es wird nichts in einer Cloud oder bei einem Anbieter zwischengelagert.
  • Angekündigte Geräte-Namen sind frei wählbar — du kannst dein Gerät "Mein Computer" nennen.
  • Detail-Datenschutzerklärung: siehe DATENSCHUTZ.html im Programmordner.
