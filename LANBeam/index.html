LAN-TRANSFER · WINDOWS

Dateien senden, ohne Cloud-Umweg.

LANBeam schickt Dateien direkt von Gerät zu Gerät im selben WLAN — ohne Konto, ohne Cloud-Server, ohne Limit. Das Handy braucht dafür nicht mal eine App.

📡

Automatische Geräte-Erkennung

Geräte im selben WLAN erscheinen von selbst in der Liste, sobald LANBeam läuft — kein Pairing, keine IP-Adresse eintippen.

🔀

Direkte Übertragung

Dateien wandern direkt zwischen den Geräten hin und her, nicht über einen fremden Server.

📱

Handy ohne App

Im Browser eine Adresse aufrufen oder QR-Code scannen — Dateien vom Handy landen direkt auf dem PC, ganz ohne Installation.

🖱️

Drag & Drop

Datei einfach auf das Zielgerät ziehen und ablegen, fertig.

🔒

Keine Cloud, keine Telemetrie

Es läuft kein Server im Hintergrund, es werden keine Nutzerprofile erstellt und keine Daten an Dritte weitergegeben.

🛡️

Firewall in einem Schritt

Der Setup-Wizard richtet die nötigen Firewall-Regeln auf Wunsch automatisch ein.

Ehrlich zusammengefasst

LANBeam ist lokale Software. Sie sendet keine Daten an unsere Server, sammelt keine Telemetrie, erstellt keine Nutzerprofile und verwendet kein Konto. Alle Datei-Übertragungen passieren direkt zwischen Geräten im selben Netzwerk. Details in der Datenschutzerklärung.
